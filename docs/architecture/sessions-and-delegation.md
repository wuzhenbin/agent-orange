# 会话、压缩与子代理

[返回文档目录](../README.md)

## 会话存储

`SessionManager` 支持持久化与内存模式。主代理初始会话持久化到 `~/.agent-orange/sessions/`，文件名包含时间戳与会话 ID，扩展名为 `.jsonl`。子代理默认不落盘。

| 条目           | 内容                                             |
| -------------- | ------------------------------------------------ |
| `session`      | 文件头：会话 ID、时间和工作目录                  |
| `message`      | 用户、助手或工具结果消息                         |
| `compaction`   | 摘要、首条保留消息 ID、压缩前 Token 数和可选详情 |
| `session_info` | 会话显示名称等元信息                             |

普通条目包含 `id`、`parentId` 与时间戳。上下文重建沿当前叶子到根节点的路径解析消息，并处理压缩边界；因此读取文件条目列表不等于取得可直接发送给模型的消息列表。

## 新建与恢复

`AgentContext.newSession` 根据当前会话是否持久化选择新存储，再重建运行时。`switchSession` 打开历史文件，检查记录的工作目录是否存在后替换运行时。TUI 随后重绑订阅，并通过 `buildSessionContext` 恢复上下文和画面。

当前替换运行时沿用原 `AgentDefinition` 和工厂工作目录，模型取自默认设置。不要假定跨目录恢复会自动重建工具目录、角色资源或恢复历史模型。初次创建主代理时额外注入的委派工具，在 `createRuntime` 路径中也未重新合入。

## 重试与上下文压缩

`AgentSession` 在一次执行结束后检查可重试错误、压缩需求和队列。重试设置默认启用，最多 3 次，基础延迟 2000 毫秒；具体错误筛选位于 `session.ts`。

手动 `/compact` 调用 `AgentSession.compact`。自动压缩由上下文阈值或溢出触发，默认预留 16384 Token、保留近期 20000 Token。`harness/compaction.ts` 选择压缩范围并生成摘要，结果写成压缩条目，再重建运行上下文。

压缩保留历史记录，通过摘要减少后续请求的上下文。溢出恢复最多进行一次压缩后重试；成功完成的回答即使超过配置窗口，也不会因为压缩而重复生成。

## 子代理委派

主代理提示词展示可用角色，模型通过 `delegate_task` 选择角色和任务。当前工具参数名是 `name` 与 `propmpt`，后者拼写与源码一致。

`AgentManager.createSubagentExcute` 创建独立实例并订阅会话事件，向界面转发开始、工具调用、工具结果和结束信息。任务结束后提取最后一条助手消息的文本，释放该会话，并把文本作为工具结果交回主代理。

子代理使用自己的会话上下文，不自动继承主代理对话。多个委派调用可以随工具批次并行执行。当前委派工具的取消信号会结束等待，但未传入子代理执行方法，因此不能视为对子代理执行的完整取消。
